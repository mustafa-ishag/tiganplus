### 3. معادلات الحساب

#### المستخلصات الجزئية:
```
الضريبة = المبلغ الإجمالي × 15%
الصافي = المبلغ الإجمالي - الضريبة
```

**مثال:**
```
المبلغ الإجمالي: 100,000 ريال
الضريبة: 15,000 ريال
الصافي: 100,000 - 15,000 = 85,000 ريال
```

#### المستخلصات النهائية للجزئية:
```
الضريبة = المبلغ الإجمالي × 15%
الصافي = المبلغ الإجمالي + الضريبة - الغرامات
```

**مثال:**
```
المبلغ الإجمالي: 100,000 ريال
الضريبة: 15,000 ريال
الغرامات: 5,000 ريال
الصافي: 100,000 + 15,000 - 5,000 = 110,000 ريال
```

### 10. مثال عملي مقارن

```
الصافي: 100,000 - 15,000 = 85,000 ريال
```

##### المستخلص النهائي للجزئي:

```
المبلغ الإجمالي: 100,000 ريال

الصافي: 100,000 + 15,000 - 5,000 = 110,000 ريال
```

### 11. سير العمل (Workflow)

#### المستخلصات الجزئية:
```
1. إنشاء مستخلص جزئي
2. إضافة أوامر العمل
3. إدخال تاريخ الإنجاز لكل أمر
4. حساب الصافي = الإجمالي - الضريبة
5. اعتماد المستخلص
```

#### المستخلصات النهائية للجزئية:
```
1. يجب أن يكون هناك مستخلص جزئي موجود
2. إنشاء مستخلص نهائي للجزئي
3. ربطه بالمستخلص الجزئي
4. إضافة أوامر العمل (من المستخلص الجزئي)
5. إضافة الغرامات
6. استخدام تاريخ الإنجاز من المستخلص الجزئي
7. حساب الصافي = الإجمالي + الضريبة - الغرامات
8. اعتماد المستخلص
```

### 12. الأخطاء الشائعة

#### المستخلصات الجزئية:
- ❌ نسيان إدخال تاريخ الإنجاز
- ❌ خطأ في حساب الضريبة
- ❌ عدم تطابق رقم أمر العمل مع نوعه

#### المستخلصات النهائية للجزئية:
- ❌ **المستخلص الجزئي غير موجود**
- ❌ **أمر العمل غير موجود في المستخلص الجزئي**
- ❌ **محاولة إدخال تاريخ الإنجاز (غير مطلوب)**
- ❌ خطأ في حساب الصافي (نسيان الغرامات)
- ❌ عدم تطابق رقم أمر العمل مع نوعه

### 13. التحقق من البيانات

```php
// التحقق من وجود أمر العمل
```

#### المستخلصات النهائية للجزئية:

```php
$workOrderInPartial = checkWorkOrderInPartialExtract($workOrderId, $partialExtractId);

$completionDate = getCompletionDateFromPartialExtract($workOrderId, $partialExtractId);

// حساب الصافي
$net = $total + $tax - $penalty;
```

## 🎯 الخلاصة

### الفروقات الرئيسية الثلاثة:

1. **الغرامات** 🚨
   - الجزئية: لا توجد
   - النهائية: موجودة ومؤثرة في الحساب

2. **حساب الصافي** 💰
   - الجزئية: `الإجمالي - الضريبة`
   - النهائية: `الإجمالي + الضريبة - الغرامات`

3. **تاريخ الإنجاز** 📅
   - الجزئية: يُدخل يدوياً
   - النهائية: يُستخدم من المستخلص الجزئي
