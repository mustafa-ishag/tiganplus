# دليل الحساب التلقائي للمبالغ - المستخلصات النهائية للجزئية

## 🎯 نظرة عامة

تم تحديث نظام الاستيراد ليقوم **بحساب جميع المبالغ تلقائياً** بناءً على قيمة المستخلص والغرامة فقط.

## ✅ ما الذي تُدخله أنت؟

عند استيراد المستخلصات النهائية للجزئية، تحتاج فقط إلى إدخال:

### البيانات الأساسية:
1. **رقم المستخلص** (مثال: FFPE-2025-001)
2. **الفرع** (مثال: الفرع الرئيسي)
3. **تاريخ المستخلص** (مثال: 2025-01-15)
4. **المستخلص الجزئي المرتبط** (مثال: PE-2025-001)
5. **مرحلة الاعتماد** (مثال: draft)

### بيانات أوامر العمل (لكل أمر عمل):
6. **رقم أمر العمل** (مثال: 123)
7. **نوع أمر العمل** (مثال: CON)
8. **قيمة المستخلص** ⭐ (مثال: 50000)
9. **الغرامة** ⭐ (مثال: 2500)

---

## 🤖 ما الذي يحسبه النظام تلقائياً؟

النظام يحسب تلقائياً:

### 1. المبلغ الإجمالي
```
المبلغ الإجمالي = مجموع قيم المستخلصات لجميع أوامر العمل
```

**مثال:**
- أمر عمل 1: قيمة المستخلص = 50,000
- أمر عمل 2: قيمة المستخلص = 30,000
- **المبلغ الإجمالي = 80,000**

### 2. الضريبة
```
الضريبة = المبلغ الإجمالي × 15%
```

**مثال:**
- المبلغ الإجمالي = 80,000
- **الضريبة = 12,000**

### 3. إجمالي الغرامات
```
إجمالي الغرامات = مجموع الغرامات لجميع أوامر العمل
```

**مثال:**
- أمر عمل 1: الغرامة = 2,500
- أمر عمل 2: الغرامة = 1,500
- **إجمالي الغرامات = 4,000**

### 4. المبلغ الصافي
```
المبلغ الصافي = المبلغ الإجمالي + الضريبة - إجمالي الغرامات
```

**مثال:**
- المبلغ الإجمالي = 80,000
- الضريبة = 12,000
- إجمالي الغرامات = 4,000
- **المبلغ الصافي = 88,000**

### ملف Excel الذي تُدخله:

| رقم المستخلص | الفرع | تاريخ المستخلص | المستخلص الجزئي المرتبط | مرحلة الاعتماد | رقم أمر العمل | نوع أمر العمل | قيمة المستخلص | الغرامة |
|--------------|-------|----------------|-------------------------|----------------|---------------|---------------|---------------|---------|
| FFPE-2025-001 | الفرع الرئيسي | 2025-01-15 | PE-2025-001 | draft | 123 | CON | 50000 | 2500 |
| FFPE-2025-001 | الفرع الرئيسي | 2025-01-15 | PE-2025-001 | draft | 456 | TO3 | 30000 | 1500 |

### ما يحسبه النظام:

```
المبلغ الإجمالي = 50,000 + 30,000 = 80,000
الضريبة = 80,000 × 15% = 12,000
إجمالي الغرامات = 2,500 + 1,500 = 4,000
المبلغ الصافي = 80,000 + 12,000 - 4,000 = 88,000
```

## 🔄 كيف يعمل النظام؟

### 1. قراءة البيانات
```php
// قراءة قيمة المستخلص والغرامة من Excel
$extractValue = floatval($row['قيمة المستخلص'] ?? 0);
$penaltyAmount = floatval($row['الغرامة'] ?? 0);
```

### 2. تجميع البيانات حسب المستخلص
```php
// تجميع جميع أوامر العمل التابعة لنفس المستخلص
$extractGroups[$extractNumber][] = [
    'extract_value' => $extractValue,
    'penalty_amount' => $penaltyAmount
];
```

### 3. حساب المبالغ
```php
// حساب المبالغ لكل مستخلص
$totalExtractValue = array_sum($extractValues);
$totalPenaltyAmount = array_sum($penaltyAmounts);
$taxAmount = $totalExtractValue * 0.15;
$netAmount = $totalExtractValue + $taxAmount - $totalPenaltyAmount;
```

### 4. تحديث البيانات
```php
// تحديث جميع الصفوف التابعة لنفس المستخلص
foreach ($indices as $index) {
    $previewData[$index]['total_amount'] = $totalExtractValue;
    $previewData[$index]['tax_amount'] = $taxAmount;
    $previewData[$index]['total_penalty_amount'] = $totalPenaltyAmount;
    $previewData[$index]['net_amount'] = $netAmount;
}
```

## ⚠️ نقاط مهمة

### 1. لا تُدخل المبالغ المحسوبة
❌ **خطأ شائع:**
```
إدخال المبلغ الإجمالي، الضريبة، إجمالي الغرامات، المبلغ الصافي في الملف
```

✅ **الصحيح:**
```
فقط أدخل قيمة المستخلص والغرامة لكل أمر عمل
```

### 2. المستخلص الواحد يمكن أن يحتوي على عدة أوامر عمل
```
FFPE-2025-001 | ... | 123 | CON | 50000 | 2500
FFPE-2025-001 | ... | 456 | TO3 | 30000 | 1500
FFPE-2025-001 | ... | 789 | TR7 | 20000 | 1000
```

النظام سيجمع جميع القيم والغرامات ويحسب المبالغ الإجمالية.

### 3. الحساب يتم لكل مستخلص على حدة
إذا كان لديك مستخلصان مختلفان:
```
FFPE-2025-001 | ... | 123 | CON | 50000 | 2500
FFPE-2025-001 | ... | 456 | TO3 | 30000 | 1500
FFPE-2025-002 | ... | 789 | TR7 | 40000 | 3000
```

النظام سيحسب:
- **FFPE-2025-001**: إجمالي = 80,000
- **FFPE-2025-002**: إجمالي = 40,000
