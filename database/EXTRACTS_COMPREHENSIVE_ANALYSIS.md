# تحليل شامل لنظام المستخلصات الثلاثة
## Comprehensive Analysis of Three Extract Types System

---

## 🎯 أنواع المستخلصات الثلاثة

### 1️⃣ المستخلصات الجزئية (Partial Extracts)
**الغرض**: صرف جزئي لقيمة أوامر العمل

**الخصائص**:
- صرف جزئي من قيمة أمر العمل
- يمكن إنشاء عدة مستخلصات جزئية لنفس أمر العمل
- تحتوي على ضريبة (15%)
- لا تحتوي على غرامات
- مرتبطة بأوامر عمل متعددة

**الجداول**:
- `partial_extracts` - البيانات الأساسية
- `partial_extract_work_orders` - ربط أوامر العمل
- `partial_extract_attachments` - المرفقات
- `partial_extract_activities` - السجل النشاط
- `partial_extract_import_export_logs` - سجل الاستيراد/التصدير

**المسار**: `/public/extracts/partial/`

---

### 2️⃣ المستخلصات النهائية العادية (Final Regular Extracts)
**الغرض**: صرف كامل لقيمة أوامر العمل مع الغرامات

**الخصائص**:
- صرف كامل من قيمة أمر العمل
- تحتوي على ضريبة (15%)
- تحتوي على غرامات (penalties)
- مستقلة تماماً عن المستخلصات الجزئية
- مرتبطة بأوامر عمل متعددة

**الجداول**:
- `final_regular_extracts` - البيانات الأساسية
- `final_regular_extract_work_orders` - ربط أوامر العمل
- `final_regular_extract_attachments` - المرفقات
- `final_regular_extract_activities` - السجل النشاط
- `final_regular_extract_import_export_logs` - سجل الاستيراد/التصدير

**المسار**: `/public/extracts/final-regular/`

---

### 3️⃣ المستخلصات النهائية للجزئية (Final For Partial Extracts)
**الغرض**: إكمال المستخلصات الجزئية بصرف القيمة المتبقية

**الخصائص**:
- **مرتبطة بمستخلص جزئي محدد** (علاقة 1:1)
- تصرف القيمة المتبقية من أمر العمل
- تحتوي على ضريبة (15%)
- تحتوي على غرامات (penalties)
- تحتوي على ضريبة المستخلص الجزئي الأصلي
- لا يمكن إنشاء مستخلص نهائي للجزئية إلا إذا:
  - المستخلص الجزئي في مرحلة "مصروف" أو "مالية الطائف"
  - جميع أوامر العمل مؤكدة شهادة الإنجاز
  - لم يتم إنشاء مستخلص نهائي للجزئية مسبقاً

**الجداول**:
- `final_for_partial_extracts` - البيانات الأساسية
- `final_for_partial_extract_work_orders` - ربط أوامر العمل
- `final_for_partial_extract_attachments` - المرفقات
- `final_for_partial_extract_activities` - السجل النشاط
- `final_for_partial_extract_import_export_logs` - سجل الاستيراد/التصدير

**المسار**: `/public/extracts/final-for-partial/`

## 🔄 العلاقات بين الأنواع

```
أمر عمل (Work Order)
    ↓
    ├─→ مستخلص جزئي (Partial Extract)
    │       ↓
    │       └─→ مستخلص نهائي للجزئية (Final For Partial)
    │
    └─→ مستخلص نهائي عادي (Final Regular Extract)
```

## 📁 الملفات الرئيسية لكل نوع

### المستخلصات الجزئية:
- `index.php` - قائمة المستخلصات
- `create.php` - إنشاء مستخلص جديد
- `view.php` - عرض تفاصيل المستخلص
- `edit.php` - تعديل المستخلص
- `delete-ajax.php` - حذف المستخلص
- `export.php` - تصدير البيانات
- `import.php` - استيراد البيانات

### المستخلصات النهائية العادية:
- نفس الملفات كالمستخلصات الجزئية

### المستخلصات النهائية للجزئية:
- نفس الملفات كالمستخلصات الجزئية
- ملف إضافي: `get-partial-extract-details.php` - جلب تفاصيل المستخلص الجزئي
