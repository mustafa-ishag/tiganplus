# نظام تِقان لإدارة أعمال شركة المقاولات
## Tiqan ERP System for Construction Company Management

نظام إدارة موارد المؤسسة (ERP) متكامل مصمم خصيصاً لإدارة أعمال شركات المقاولات في المملكة العربية السعودية.

## المميزات الرئيسية

### 🏢 إدارة الفروع
- إدارة متعددة الفروع مع دعم كامل للطائف ورنية
- تتبع معلومات الفروع التفصيلية
- إدارة مديري الفروع والموظفين
- تقارير أداء الفروع

### 📋 إدارة أوامر العمل
- نظام شامل لإدارة أوامر العمل برقم 9 أرقام
- دعم أنواع أوامر العمل المختلفة (3 أرقام)
- تصنيف حسب الأقسام (توصيلات/مشاريع)
- ربط بالفروع والجهات الحالية
- إدارة النماذج المرفقة (الكشط، الحفر الدقيق، التخريد، F1، شهادة الإنجاز)

### 💰 نظام المستخلصات المتقدم
- **المستخلصات الجزئية**: صرف جزئي لقيمة أوامر العمل
- **المستخلصات النهائية للجزئية**: إكمال المستخلصات الجزئية
- **المستخلصات النهائية العادية**: صرف كامل مع الغرامات
- آلية اختيار أوامر العمل المكونة من جزئين
- حسابات تلقائية للضرائب (15%)
- نظام اعتماد متدرج بـ 6 مراحل

### 👥 إدارة المستخدمين والصلاحيات
- نظام أدوار وصلاحيات متقدم
- 8 أدوار أساسية من مدير النظام إلى المستخدم العادي
- صلاحيات مقيدة حسب الفروع
- تسجيل دخول آمن مع تذكر المستخدم

### 📊 التقارير والإحصائيات
- تقارير شاملة للفروع وأوامر العمل والمستخلصات
- رسوم بيانية تفاعلية
- تصدير متعدد الصيغ (PDF, Excel, CSV)
- فلترة متقدمة حسب الفروع والتواريخ

## المتطلبات التقنية

### الخادم
- **PHP**: 8.3 أو أحدث
- **MySQL**: 8.0 أو أحدث
- **Apache/Nginx**: مع دعم mod_rewrite
- **phpMyAdmin**: 5.2+ (للإدارة)

### المتصفح
- **Bootstrap**: 5.3+ (RTL Support)
- **DataTables**: 1.13+ (للجداول التفاعلية)
- **Chart.js**: للرسوم البيانية
- **Font Awesome**: 6.4+ للأيقونات
- **SweetAlert2**: للتنبيهات

### الأمان
- تشفير كلمات المرور (bcrypt)
- حماية من SQL Injection
- حماية من XSS و CSRF
- جلسات آمنة مع انتهاء صلاحية
- تسجيل محاولات الدخول الفاشلة

## التثبيت

### 1. متطلبات النظام
```bash
# تأكد من توفر PHP 8.3+
php --version

# تأكد من توفر MySQL 8.0+
mysql --version
```

### 2. تحميل المشروع
```bash
# استنساخ المشروع
git clone https://github.com/your-repo/etganplus.git
cd etganplus

# أو تحميل الملفات مباشرة إلى مجلد htdocs
```

### 3. إعداد قاعدة البيانات
```sql
-- إنشاء قاعدة البيانات
CREATE DATABASE etgan_erp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- استيراد الهيكل والبيانات الافتراضية
mysql -u root -p etgan_erp < database/etgan_erp.sql
```

### 4. تكوين النظام
```php
// تحديث ملف config/config.php
define('DB_HOST', 'localhost');
define('DB_NAME', 'etgan_erp');
define('DB_USER', 'your_username');
define('DB_PASS', 'your_password');
```

### 5. إعداد الصلاحيات
```bash
# إعطاء صلاحيات الكتابة لمجلد الرفع
chmod 755 uploads/
chown www-data:www-data uploads/
```

## الاستخدام

### تسجيل الدخول الأولي
- **اسم المستخدم**: admin
- **كلمة المرور**: password
- **رابط النظام**: http://localhost/etganplus

### إعداد الفروع
1. انتقل إلى "إدارة الفروع"
2. الفروع الافتراضية: الطائف (TAF) ورنية (RAN)
3. يمكن إضافة فروع جديدة أو تعديل الموجودة

### إنشاء المستخدمين
1. انتقل إلى "إدارة المستخدمين"
2. اختر الدور المناسب
3. ربط المستخدم بالفرع (اختياري)
4. تحديد الصلاحيات

### إدارة أوامر العمل
1. انتقل إلى "أوامر العمل"
2. إضافة أمر عمل جديد برقم 9 أرقام
3. تحديد النوع والقسم والفرع
4. رفع النماذج المطلوبة
5. تأكيد شهادة الإنجاز

### إنشاء المستخلصات
1. اختيار نوع المستخلص (جزئي/نهائي)
2. استخدام آلية الجزئين لاختيار أوامر العمل
3. إدخال القيم والتواريخ
4. مراجعة الحسابات التلقائية
5. إرسال للاعتماد

## الأمان والصيانة

```bash

mysqldump -u root -p tiqan_erp > backup_$(date +%Y%m%d).sql

# نسخ احتياطي للملفات
tar -czf files_backup_$(date +%Y%m%d).tar.gz uploads/
```
